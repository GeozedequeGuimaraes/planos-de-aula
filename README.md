# Planos de Aula

Sistema de gerenciamento de planos de aula com sugestão inteligente de conteúdos.

## Tecnologias

- **Backend:** Node.js, Express, Prisma ORM
- **Banco de dados:** PostgreSQL
- **Frontend:** React (Vite)
- **IA:** OpenAI GPT-4o
- **Infra:** Docker, Docker Compose
